# Рецепты

Рецепт — это ответ на одну конкретную задачу. Не обзор возможностей и не учебник, а последовательность действий, после которой задача решена.

Если вы ещё не запускали роутер, начните с [обучения](../tutorial/index.md): рецепты рассчитаны на то, что базовый пример у вас уже работает.

| Задача | Рецепт |
| --- | --- |
| слушателям нужны сервисы проекта | [Подключить контейнер](container.md) |
| хочется видеть, какие события пришли и кто их обработал | [Настроить лог](logging.md) |
| слушатель упал — что дальше | [Обработать ошибки слушателей](errors.md) |
| события приходят из очереди | [Запустить воркер](workers.md) |
| проект на Bitrix, обработчики в `init.php` | [Подключить события Bitrix](bitrix.md) |
| данные события — не массив, а объект | [Передать данные объектом](typed-events.md) |
| код знает только PSR-14 | [Подключить через PSR-14](psr14.md) |
| маршруты в Slim уже знакомы | [Перейти со Slim](from-slim.md) |
