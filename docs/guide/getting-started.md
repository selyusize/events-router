# Быстрый старт

## Требования

- PHP 8.1 или новее
- Composer

## Установка

```bash
composer require selyusize/events-router
```

## Проверка установки

--8<-- "getting-started/check-installation.php:example"

Вывод:

```text
--8<-- "getting-started/check-installation.out"
```
