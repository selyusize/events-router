# PSR-14

`Psr14EventDispatcher` — роутер под стандартным интерфейсом `Psr\EventDispatcher\EventDispatcherInterface`. Нужен, когда код или сторонняя библиотека знает только PSR-14.

```php
--8<-- "psr14/psr14.php:example"
```

```text
--8<-- "psr14/psr14.out"
```

## Как объект превращается в событие

| Что передали в `dispatch()` | Что получает роутер |
| --- | --- |
| объект, реализующий `EventInterface` (например, `Event`) | его же, как есть |
| любой другой объект | `new Event(маппер($object), $object)`: имя даёт маппер из конструктора, сам объект становится payload |
| любой другой объект, а маппера нет | исключение [`UnmappableEvent`](../errors/unmappable-event.md) |

Имя события по имени класса не угадывается: правило задаёте вы, явно.

## Что гарантирует адаптер

- Как требует PSR-14, `dispatch()` возвращает тот же объект, что получил.
- Если объект реализует `StoppableEventInterface`, слушатель может остановить рассылку: роутер проверяет payload перед каждым слушателем.
- Ошибки слушателей обрабатываются так же, как в `EventRouter::dispatch()`: обработчик ошибок и стратегия роутера. Отчёт о рассылке PSR-14 не возвращает — если он нужен, вызывайте роутер напрямую.
