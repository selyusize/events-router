# UnresolvableHandler

`Selyusize\EventsRouter\Exception\UnresolvableHandler`

Класс, указанный в маршруте или в настройках роутера, нельзя использовать: его нет, он не реализует нужный интерфейс или контейнер вернул что-то другое.

В начале сообщения сказано, о чём речь:

| Начало сообщения | Где указан класс | Нужный интерфейс |
| --- | --- | --- |
| `Слушатель "…"` | `listen()` | `ListenerInterface` |
| `Middleware "…"` | `add()` на роутере, группе или маршруте | `MiddlewareInterface` |
| `Обработчик ошибок "…"` | `setErrorHandler()` | `ErrorHandlerInterface` |

## Когда возникает

Классы не загружаются при регистрации маршрутов, поэтому ошибка видна, когда класс понадобился впервые:

- **слушатель или middleware маршрута/группы** — слушатель получает в отчёте статус `Failed`, остальные слушатели работают;
- **middleware роутера** (`$events->add()`) или **обработчик ошибок** — исключение выходит из `dispatch()` наружу.

## Причины и исправления

| Сообщение | Причина | Как исправить |
| --- | --- | --- |
| класс не найден | опечатка в имени класса или класс не подключён автозагрузкой | проверьте `use` и имя класса, выполните `composer dump-autoload` |
| класс не реализует … | указан класс, который не является слушателем, middleware или обработчиком ошибок | добавьте нужный `implements` и метод: `public static function handle(EventInterface $event): void` для слушателя, `process(EventInterface $event, EventHandlerInterface $next): void` для middleware, `handle(Throwable $error, EventInterface $event, string $listener): void` для обработчика ошибок |
| контейнер вернул …, а нужен … | в контейнере под этим именем зарегистрирован другой объект | исправьте определение в контейнере |

## Как роутер получает классы

- **Слушатель** статичный: роутер проверяет, что класс есть и реализует `ListenerInterface`, и вызывает `Listener::handle($event)`. Объект не создаётся, контейнер не используется.
- **Middleware и обработчик ошибок** — объекты:
    1. если передан объект — он и используется;
    2. если роутер создан с контейнером и `$container->has($class)` — объект берётся из контейнера;
    3. иначе класс создаётся через `new` без аргументов. Если конструктору нужны аргументы, зарегистрируйте класс в контейнере.
