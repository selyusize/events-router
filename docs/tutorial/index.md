# Первый роутер

За десять минут вы установите библиотеку, напишете слушателя, опишете маршрут и отправите первое событие. В конце будет видно, кто его получил и чем всё закончилось.

Никакой теории по пути. Только шаги, каждый из которых даёт результат. Разбираться, почему всё устроено именно так, будем потом — в разделе [Как это устроено](../explanation/index.md).

Что понадобится: PHP 8.1 или новее и Composer.

## Шаг 1. Установите библиотеку

```bash
composer require selyusize/events-router
```

Проверьте, что всё на месте:

```php
--8<-- "getting-started/check-installation.php:example"
```

Должно получиться:

```text
--8<-- "getting-started/check-installation.out"
```

## Шаг 2. Напишите слушателя

Слушатель — это реакция на событие. Один класс, один статичный метод `handle()`:

```php
--8<-- "getting-started/quick-start.php:listener"
```

`$event->getAttribute('order_id')` — номер заказа. Откуда он возьмётся, увидите на следующем шаге.

## Шаг 3. Опишите маршрут

Маршруты лежат в отдельном файле, как HTTP-маршруты в Slim. Создайте `events.php`:

```php
--8<-- "getting-started/events.php:example"
```

Этот маршрут ловит все события вида `shop.order.<что угодно>.paid`. То, что стоит на месте `{order_id}`, попадёт к слушателю в атрибут `order_id`.

## Шаг 4. Отправьте событие

Создайте роутер, подключите маршруты и разошлите событие:

```php
--8<-- "getting-started/quick-start.php:dispatch"
```

Результат:

```text
--8<-- "getting-started/quick-start.out"
```

Роутер нашёл маршрут, вытащил из имени события `42`, вызвал слушателя и вернул отчёт. `hasFailures()` говорит, что все слушатели отработали без исключений.

## Шаг 5. Посмотрите, что происходило

Отчёт хорош в коде, но в работающем приложении хочется видеть историю. Включите лог рассылки — он пишет каждое событие и каждого вызванного слушателя:

```php
--8<-- "logging/dispatch-log.php:example"
```

В логе появятся две записи. Первая — о рассылке, вторая — об упавшем слушателе:

```text
--8<-- "logging/dispatch-log.out"
```

Второй слушатель упал, но первый отработал. Ошибка одного слушателя не ломает остальных: она попадает в отчёт и в лог, а рассылка продолжается.
