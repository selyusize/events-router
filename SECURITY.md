# Политика безопасности

## Поддерживаемые версии

До 1.0 исправления безопасности выходят только для последней минорной версии. Обновление внутри 0.x может менять API — см. [CHANGELOG](CHANGELOG.md).

| Версия | Поддерживается |
| ------ | -------------- |
| 0.5.x  | ✅             |
| < 0.5  | ❌             |

## Как сообщить об уязвимости

Не создавайте публичный issue. Напишите на **moontesearch@gmail.com** с темой `events-router: security`.

В письме укажите:

- версию библиотеки и PHP;
- что происходит и чем это опасно;
- шаги или минимальный код для воспроизведения;
- если есть — идею исправления.

## Что будет дальше

- Подтвержу получение в течение 3 рабочих дней.
- В течение 10 рабочих дней отвечу, принята ли уязвимость, и, если принята, назову ориентировочный срок исправления.
- Пока идёт работа, сообщаю о ходе не реже раза в неделю.
- Если уязвимость принята: выпускаю патч-версию, описываю проблему в CHANGELOG и GitHub Security Advisory, упоминаю автора отчёта, если он не против.
- Если отклонена: объясню почему. Если проблема на самом деле в зависимости (например, PHP-DI), подскажу, куда её отправить.

Пожалуйста, не раскрывайте детали публично до выхода исправления или до истечения 90 дней с момента отчёта — что наступит раньше.
